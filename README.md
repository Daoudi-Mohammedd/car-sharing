# 🚗 Car Sharing Web Application

Full-stack ride-sharing platform developed as part of a Software Engineering university project.
The application enables users to create and manage rides, communicate in real time, and interact through a modern web interface.

---

## ✨ Features

- User authentication & authorization
- Ride creation and management
- Real-time communication with WebSockets
- Interactive map integration
- RESTful API architecture
- Responsive frontend UI
- Dockerized development environment
- API documentation with Swagger/OpenAPI

---

## 🏗️ Architecture

Frontend → Backend → Database

### Components

- Angular Frontend
- Spring Boot Backend
- PostgreSQL Database
- Docker Infrastructure
